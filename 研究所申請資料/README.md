# 研究所申請資料

本資料夾整理台灣大學研究所甄試申請所需的研究定位、文件清單與準備草稿。

目前主攻方向：

1. **台大財務金融學系暨研究所碩士班 甲組（主修財務金融）**
2. 台大商學研究所
3. 台大資訊管理學系暨研究所

## 申請主軸

> 具會計與金融訓練，並已使用 Python、面板資料計量方法與 Tableau 完成銀行及金融科技研究，希望在研究所進一步研究數位金融、銀行競爭與資料驅動的金融決策。

## 目前優勢

- University of Birmingham BSc (Hons) Accounting and Finance
- 344 筆 bank-year observations、39 家銀行、2014-2022 年
- Indonesia、Malaysia、Thailand 銀行面板研究
- Python、pandas、NumPy、linearmodels
- Bank and year fixed effects、clustered standard errors、robustness analysis
- Tableau 商業分析 Story 與 Tableau Public 作品
- Evershine CPAs 跨國稅務實習
- 英文授課學位與英文研究報告經驗

## 台大財金所甄試重點

- 116 學年度甄試限報考一組；目前最適合甲組（主修財務金融）。
- 官方列出的申請資料包括：報名表、個人資料表、學歷證明、正式成績單、學業排名證明、學習計畫書及其他能力經歷證明。
- 財金所官方頁面明確寫明：**不接受推薦信**。
- 財金所官方頁面寫明畢業有英文檢定成績要求，但未在招生頁直接列出完整分數；需向系所確認英語授課學位是否可抵或豁免。
- 甄試簡章、報名日期與檔案規格仍以台大研教組正式公告為準。
